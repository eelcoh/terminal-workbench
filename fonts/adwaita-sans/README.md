# Adwaita Sans

Unmodified Adwaita Sans Regular from Fedora package
`adwaita-sans-fonts-50.0-1.fc44.noarch`, bundled for Workbench interface text on
Linux and macOS. This Inter-derived face is separate from the terminal font.
SIL Open Font License 1.1; attribution and license are in OFL.txt.

SHA-256: `8381c33b9a44f066f2b99dba3d416a2342891e28c956a35dfd8d16ee2987e6d4`.

Upstream: `git@gitlab.gnome.org:GNOME/adwaita-fonts.git`.
The font and license came from the locally installed Fedora package. Builds
embed these committed bytes; no system font discovery or download is required.
The prototype uses the variable font's default regular instance.
