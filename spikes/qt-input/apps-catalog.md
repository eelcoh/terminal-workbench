# App catalog sources

`apps-catalog.json` is generated by `scripts/prepare-app-catalog.py` and checked
in, so Band needs no network to show it. Refresh it by running the script
(awesome-tuis is cloned over SSH; Homebrew's index comes from formulae.brew.sh),
review the diff, and run `just toolkit-apps-test` and `just toolkit-ui-test`.

- **Selection:** [awesome-tuis](https://github.com/rothgar/awesome-tuis)
  (revision in the file). The list has no licence, so only which projects it
  lists is used, by repository URL, with the projects' own names. Its
  descriptions are not copied.
- **Descriptions, formula names and commands:** Homebrew's formula index
  (`formula.json`) and executables list, from homebrew-core (fetched
  2026-11-07, homebrew-core `dfd7841e9a4c6f314134f798f1764ce6a335517e`), under
  the licence below.

The ten curated apps in `ui_apps.cpp` have their own descriptions and system
package names.
